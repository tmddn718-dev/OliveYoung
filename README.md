# 올리브영 오늘드림 품절 UX 프로토타입

첨부한 올리브영 옵션 바텀시트와 `DESIGN_SYSTEM.md`를 기준으로 제작한 390px iOS 클릭형 프로토타입입니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 확인할 수 있는 흐름

- 8개 상품 옵션의 혼합 재고 상태
- 일반배송, 픽업, 모두 가능, 전체 품절, 조회 전 CTA
- 일반배송과 매장 픽업 비교
- 픽업 매장 재고와 준비 시간 확인
- 재입고 알림 신청과 완료
- 재고 조회 실패 후 재시도
- 주문 중 픽업 재고 소진 후 다른 매장 선택
- 옵션 목록 복귀 시 스크롤 위치 유지

모든 재고, 매장, 수령 시간은 UX 시뮬레이션용 가상 데이터입니다.
