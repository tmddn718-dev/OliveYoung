# 올리브영 오늘드림 품절 이후 구매 경험 · 인터랙티브 프로토타입

비공식 포트폴리오 UX/UI 개선 시안입니다. 오늘드림 옵션이 품절돼도 다른 구매 방법(일반배송·매장 픽업)이나 재입고 알림으로 이어지게 하는 흐름을 390px 모바일 화면에서 직접 눌러 볼 수 있어요.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 확인할 수 있는 흐름

첫 화면에서 시나리오를 고르면 상세 → 옵션 선택 → 다른 구매 방법 → 매장 선택 → 주문/결제 → 완료까지 이어져요.

- Flow A: 오늘드림 품절 → 일반배송 구매
- Flow B: 오늘드림 품절 → 매장 픽업 구매
- Flow C: 일반배송 조회 실패 → 다시 확인 (두 번 실패 후 성공)
- Flow D: 확인한 방법 모두 불가 → 재입고 알림
- Flow E: 주문 직전 픽업 재고 변동
- Flow F: 상세 하단 패널 펼침·접힘
- Flow G: 무료배송 기준 미달 → 배송 시간대별 배송비 비교
- 옵션 선택 방식 비교: A안(하단 CTA)과 절충안(구매 가능 옵션은 바로 선택)을 첫 화면에서 바꿀 수 있어요

재고, 매장, 수량 상한, 알림 성공은 모두 시뮬레이션용 가정이고, 배송지·매장명·주소·카드 정보는 사용 화면처럼 보이게 만든 가상 예시입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 템플릿 (캔버스의 `Prototype` 보드와 같은 내용) |
| `app.js` | 작은 렌더러와 시나리오 로직 |
| `style.css` | 프레임과 공통 스타일 |
| `design/canvas-src/` | Claude Design 캔버스 원본 보드 (AS-IS 실제 앱 캡처와 TO-BE 시안) |

`index.html`과 `app.js`는 `design/canvas-src/Prototype.dc.html`에서 만든 것이라, 캔버스의 프로토타입을 고친 뒤에는 다시 맞춰야 해요.

이전 정적 프로토타입(8개 상품 옵션 시트 기반)은 git 기록과 `oliveyoung-soldout-mobile.html`에 남아 있어요.
